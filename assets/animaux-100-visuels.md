# 70 illustrations supplémentaires

Les fichiers `animaux-100-1.png` à `animaux-100-7.png` sont sept planches de dix animaux, organisées en cinq colonnes et deux lignes. Elles complètent les trente animaux déjà disponibles.

Création avec l’outil intégré ImageGen, en prenant `animaux-sons.png` comme référence graphique : papier découpé, textures aquarellées, fond ivoire, animaux doux en entier. Les prompts exacts sont dans [animaux-100-prompts.json](animaux-100-prompts.json). Les fichiers de génération originaux ont été conservés dans le dossier de génération de Codex ; les copies embarquées sont dans ce dossier.

L’ordre des animaux, la planche et la case utilisées sont définis dans `preschool.mjs` et dans [animals-100-sources.json](animals-100-sources.json). Le memory réutilise les mêmes illustrations.

Les cris sont des enregistrements réels indépendants des images. Leurs sources, auteurs, licences et modifications d’extraits sont indiqués dans [la page de crédits](../audio-credits.html).
